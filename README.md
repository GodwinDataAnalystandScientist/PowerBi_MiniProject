PowerBi_MiniProject
Amazon Sales Data Analysis and Business Intelligence Dashboard Using Power BI

1. Project Overview and Objective
Project Overview
This project focuses on analyzing Amazon sales data by performing data cleaning, transformation, and analysis using Microsoft Excel, followed by building an interactive Business Intelligence dashboard using Power BI.The project aims to convert raw transactional sales data into meaningful insights that help understand sales performance, profitability, customer segments, and regional trends.
Project Objective
The main objectives of this project are:
•	To perform data pre-processing and cleaning using Excel.
•	To analysis sales, profit, and discount patterns across regions and product categories.
•	To create an interactive Power BI dashboard for business decision-making.
•	To demonstrate practical knowledge of Excel, Power BI, and data analytics techniques.
